# Текущее состояние Rumblewersfad — рабочая база 1.2.0

## Важно перед дальнейшими изменениями

Исходники в корне этого репозитория относятся к более раннему состоянию. Они НЕ подтверждены как исходники рабочей сборки 1.2.0. Не запускайте сборку из корня в расчёте получить ту же программу и не заменяйте ею единственный рабочий экземпляр.

В папке `latest-baseline-1.2.0` сохранены файлы, предоставленные владельцем из рабочей сборки. Это контрольная база для восстановления исходников, а не готовый восстановленный проект.

## Содержимое

- `app.asar` — точная копия предоставленного архива рабочего лаунчера, включая упакованные зависимости.
- `external-resources/` — предоставленные программа значка, ICO и два файла настроек. Они находятся рядом с app.asar в рабочей папке resources.
- `recovered-runtime/` — извлечённый код и ресурсы приложения без node_modules. Основная логика доступна в dist/main/*.js; интерфейс находится в скомпилированном JS/CSS. Это не оригинальные TypeScript/React-исходники.
- `older-source-review.zip` — ранее предоставленный снимок исходников; не считать его полной версией 1.2.0.
- `SHA256SUMS.json` — контрольные суммы файлов пакета.

## Что найдено при статической проверке

- package.json рабочего приложения содержит версию 1.2.0 и точку входа dist/main/bootstrap.js.
- При запуске формируются параметры -RVGuestName и -RVGuestName64 из сохранённого profileName.
- Сохраняется прежний путь пользовательских настроек AppData/rumblewersfad.
- Поддерживается автоматический выбор Game/RumbleverseClient.exe рядом с лаунчером.
- Лаунчер использует внешний game-window-icon.ico; тот же ICO передаётся вспомогательной программе значка игры.
- Внешний ICO побайтово совпадает с assets/icon.ico внутри app.asar.
- В branding-settings.json gameWindowBranding включён.

Это проверка файлов. Принятие ника игрой/сервером, отображение двух отдельных кнопок панели задач и безопасность/поведение бинарной вспомогательной программы запуском не проверены.

## Чего здесь нет

Самой игры, внешнего Electron-исполняемого файла и остальных файлов установки Windows. По одному этому пакету нельзя восстановить всю готовую папку программы. Сохраняйте исходную папку «Готово» отдельно, без изменений. Часть вспомогательных файлов внешней сборки могла не попасть в предоставленный комплект.

## Порядок дальнейшей работы

1. Сохранить эту контрольную базу отдельным коммитом.
2. Переносить актуальную логику из recovered-runtime/dist/main в редактируемые исходники, сравнивая с прежним TypeScript.
3. Восстановить исходники интерфейса либо получить их от последней локальной версии; не подменять их молча старым React-кодом.
4. Собирать только в отдельную тестовую папку. Сохранять имена приложения, путь настроек и протоколы.
5. На Windows проверить запуск игры, ник, настройки и две отдельные кнопки с одинаковым значком; при необходимости проверить ник со второго игрового клиента.
6. Только после проверок считать восстановленный проект заменой рабочей сборке.

Не публикуйте токены, личные настройки пользователя и файлы игры без необходимых прав. Этот пакет не содержит намеренно добавленных секретов; полного аудита безопасности не проводилось.
