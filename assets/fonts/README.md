# Шрифты

Здесь лежат файлы шрифтов, подключаемые через `@font-face` в `src/renderer/theme.css`:

- `TitanOne-400.woff2` — display-шрифт (монограмма RW, заголовки, PLAY). Бесплатный аналог стиля логотипа Rumbleverse (OFL).
- `ChakraPetch-500/600/700.woff2` — UI-шрифт во всём интерфейсе, techy-стиль как у Rumbleverse (OFL).

## Как заменить шрифт на свой

1. Положите файл шрифта (`.woff2` / `.ttf`) в эту папку, например `MyDisplayFont.woff2`.
2. В `src/renderer/theme.css` замените `src:` у соответствующего `@font-face`
   (или добавьте новый блок) и при желании имя `font-family`.
3. Перезапустите лаунчер — править код больше не нужно.

Оригинальный шрифт игры Rumbleverse не распространяется по публичной лицензии,
поэтому используется подключаемая система: любой свой файл заработает автоматически.
